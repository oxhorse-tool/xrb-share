# 傲慢的小肉包 🍊

橙色嫩芽帽衫、奶黄色长垂耳的小伙伴，陪你专注工作。

这个素材包包含可导入的透明精灵图、动画预览和单帧 PNG。角色外观与动作使用 OpenAI 内置图像生成工具制作，随后完成分帧、透明背景处理、尺寸统一及检查。

## 用法一：通过 Pets 插件导入

适用于能调用 Pets 创建、校验和选择工具的 ChatGPT Work / Codex 会话。

1. 解压本包，确认会话已启用 Pets 插件。
2. 附加 `assets/spritesheet-v2.png`，或让本地会话访问这个文件。
3. 复制下面的提示词发送；也可以直接使用 [IMPORT_PROMPT.txt](IMPORT_PROMPT.txt)。

```text
@Pets 请使用 create-pet 技能导入我附加的 spritesheet-v2.png，并创建、选中桌宠「傲慢的小肉包」。

描述：橙色嫩芽帽衫、奶黄色长垂耳的软萌小伙伴，陪你专注工作。

这是已经完成的透明 v2 精灵图：1536×2288，8列11行，每格192×208。
前九行动作帧数依次为6、8、8、4、5、8、6、6、6；最后两行各8帧，为16个看向方向。
请保留现有画面与动作，不重新生成角色。先校验文件，通过后上传并创建，再将新宠物选为当前宠物，最后确认创建结果。
```

这会在接收者自己的账号里创建一份宠物。账号或工作区需要开放相应能力。

## 用法二：桌面安装链接

支持该功能的桌面客户端提供 `codex://pets/install` 安装入口，可传入公开 HTTPS 精灵图地址，并指定 `spriteVersionNumber=2`。[官方安装链接说明](https://learn.chatgpt.com/docs/app/commands)

如果你把本包上传到 GitHub：

1. 保持本目录结构，把目录里的文件放到仓库根目录，让 GitHub 展示这份 README。
2. 打开 `assets/spritesheet-v2.png`，取得能直接返回 PNG 的公开 HTTPS 地址（例如 GitHub Raw 地址）。
3. 用浏览器打开本包的 [安装链接生成器](tools/generate-install-link.html)，粘贴图片直链，版本选择 **v2**。
4. 点击“打开安装入口”，或复制生成的链接发送给朋友。
5. 导入后在客户端的 Pets 设置里选中傲慢的小肉包；桌面悬浮宠物可以通过 `/pet` 或 Show pet 显示。[官方 Pets 使用说明](https://learn.chatgpt.com/docs/pets)

生成器也会输出可粘贴到 GitHub README 的安装链接 Markdown。GitHub 或部分群聊可能不允许直接点击自定义协议；接收者可下载 ZIP，在本地打开生成器，再点击其中的安装按钮。

生成器只在浏览器本地拼接链接，不上传文件。它不能检测你填写的远程地址是否真的返回图片。GitHub 私有仓库的地址需要登录，通常不能作为公开分发直链。请使用自己的长期托管地址。

## 用法三：网页版上传

在开放 Pets 的账号与工作区里，找到 **Settings → Personalization → Pet → Select pet → Upload pet**。如果入口要求 **1536 × 1872**，上传 `assets/spritesheet-v1.png`。这个兼容版移除了末尾两行看向方向，保留全部九组动作；两份 PNG 都小于 20 MiB。[官方网页上传说明](https://learn.chatgpt.com/docs/pets)

网页中的宠物显示在受支持的 Work 会话里；桌面的悬浮宠物需要在桌面客户端安装。两种入口的保存与显示方式可能不同。[官方说明](https://learn.chatgpt.com/docs/pets)

## 动作内容

| 行（从 0 开始） | 状态 | 帧数 | 表现 |
| --- | --- | ---: | --- |
| 0 | `idle` | 6 | 安静呼吸、眨眼 |
| 1 | `running-right` | 8 | 向右小跑 |
| 2 | `running-left` | 8 | 向左小跑 |
| 3 | `waving` | 4 | 挥手打招呼 |
| 4 | `jumping` | 5 | 蹲下、起跳、落地 |
| 5 | `failed` | 8 | 失落、垂头、恢复 |
| 6 | `waiting` | 6 | 合手等待回应 |
| 7 | `running` | 6 | 专注思考与工作 |
| 8 | `review` | 6 | 检查、思索结果 |
| 9 | look A | 8 | 000°、022.5°、045°、067.5°、090°、112.5°、135°、157.5° |
| 10 | look B | 8 | 180°、202.5°、225°、247.5°、270°、292.5°、315°、337.5° |

方向角以屏幕上方为 000°，顺时针增加；090° 是屏幕右方，180° 下方，270° 左方。中间方向的变化较轻微，相邻姿态有些接近。

## 常见问题

**提示尺寸错误？** 先看上传入口要求，v2 为 1536×2288，v1 为 1536×1872；下载原文件，不要用截图或经群聊压缩的图片。

**安装链接没有反应？** 确认已安装支持 Pets 安装入口的桌面客户端，并且该功能已开放；图片地址必须是 HTTPS 直链。也可以使用 Pets 插件导入方法。

**宠物只显示静态图？** 检查系统是否启用了“减少动态效果”；Pets 会遵循此设置。[官方说明](https://learn.chatgpt.com/docs/pets)

**透明背景变成黑色？** 有些图片查看器用黑色显示透明区域。查看 PNG 的透明度，或播放 GIF 预览确认，不必另行抠图。

**我想改名字或外观？** 导入时可以指定自己的名字。改外观后需要重新检查布局、透明度、帧数量与动作；请保留一份原始 PNG。
